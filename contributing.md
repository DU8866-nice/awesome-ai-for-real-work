# Contributing / 贡献说明

Add an option that helps someone finish a concrete task. Prefer a primary repository or official documentation, a clear interface and a result that can be checked.

请补充能帮助读者完成具体任务的工具，而不是只有名字的链接。说明它适合谁、需要准备什么、结果如何核对。

## New entries / 新条目

- Link the canonical repository and the official documentation supporting the described capability.
- Explain the task and deliverable in original, concise English and Chinese.
- State desktop, visual, server, command-line or developer requirements; describe model and hosted-service dependencies.
- Identify community/enterprise or code/model license differences. Do not assume public source means every use is unrestricted.
- Check archive status and record the review date. Stars alone are insufficient.
- Update both READMEs and `docs/catalog.json`; correct the source-review record when a factual claim changes.

For a workflow, add synthetic sample input, a reusable prompt, concrete acceptance checks and a clear review level. An illustrative expected answer is not proof that an AI generated it. Never add fake test badges, unsupported superlatives, affiliate links, paid placement, real personal data, API keys or provider tokens.

新增流程需附虚构样例、可复制提示词与明确验收标准。人为定义的参考答案不能写成实测结果。不要提交真实个人资料、密钥或推广返佣链接。

## Corrections / 修正

Use a correction issue or pull request with the affected entry, a primary source and the exact replacement wording. Small, evidence-backed changes are welcome.

Original material contributed to this collection is offered under its CC0 dedication. Upstream software, model weights and linked content keep their own licenses.
