# Source review / 资料核查

Reviewed: **2026-10-26**. Counts are a dated GitHub API snapshot, not a live ranking or endorsement. / 星标为当日 API 快照，不代表效果排名。

## Method / 方法

- Read each canonical repository README and public metadata; verify the main selection is not archived. / 读取官方仓库 README 与信息，并核对主清单未归档。
- Independently describe a task, interface and preparation. No application code or upstream README is bundled. / 独立撰写用途、使用方式和准备条件。
- Applications were not individually installed or runtime-tested. Blueprint steps are not verified vendor-native integrations. / 未逐个安装运行；蓝图不是已验证的原生集成。
- A recent push is an activity signal, not proof of support or security. GitHub `NOASSERTION` means its detector did not assign a standard SPDX license; inspect the actual license and edition. / 近期推送不等于支持保证；NOASSERTION 不等于无许可或可任意商用。
